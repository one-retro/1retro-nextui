# 1retro-nextui

The 1Retro Sync pak for [NextUI](https://nextui.loveretro.games) and
[MinUI](https://github.com/shauninman/MinUI) handhelds: the pak shell, its
`pak.json` for the Pak Store, and the workflow that assembles each release.

[minui-presenter](https://github.com/josegonzalez/minui-presenter) and
[minui-list](https://github.com/josegonzalez/minui-list), both MIT.
